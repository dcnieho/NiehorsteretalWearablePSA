# The pupil-size artefact (PSA) in wearable eye trackers
This repository contains the data and code needed to reproduce the figures in Niehorster, D. C., Culemann, W., Hessels, R. S., Nyström, M., & Hooge, I. T. C. (submitted). The pupil-size artefact (PSA) in wearable eye trackers.

When using the contents of this repository in your work, please cite Niehorster et al. (submitted).

## Contents
- `data`: Raw data files
- `figures`: Figures produced by the included code when run on the included data

## How to use
1. Run the `apparent_gaze_shift.m` script.
